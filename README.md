# Ô Petit Bistrot

Site vitrine responsive pour un bistrot français.

## Structure

```text
index.html
css/
  style.css        # styles principaux et palette
  responsive.css   # adaptation mobile/tablette
  animations.css   # apparitions et préférences d’accessibilité
js/
  script.js        # navigation, onglets, avis et formulaire
```

Ouvrez simplement `index.html` dans un navigateur. Les images sont chargées depuis Unsplash et peuvent être remplacées par les visuels du restaurant.

## Un seul fichier à modifier

Les informations destinées au client sont regroupées dans `js/contenu-client.js` : nom, coordonnées, réseaux sociaux, textes, carte et avis. Il suffit de modifier ce fichier, de l’enregistrer, puis d’actualiser le site.

Le site ne contient pas de formulaire de réservation : les boutons principaux dirigent maintenant directement vers les coordonnées du restaurant.
